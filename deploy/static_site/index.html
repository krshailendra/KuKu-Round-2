How the system decides what to post first

Think of this page as the brain behind the Priority list. First we learn the whole show (characters, themes, story arc). Then every promo clip is scored for cold-open power — not by genre tag, but by hook, cliff, clarity, and fit to the series spine. The result is a post-first order a growth marketer can trust.

2 · Global ranking recipe

Type-agnostic score → campaign pack

Key rule: classification labels (emotional, cliffhanger, romantic…) are tags for experiments. They are excluded from the numeric score so we never over-index one vibe. Weights below come from the loaded deliverable.

What drives series_global_score

✓ Ranking does

  • Prefer cold-open hooks a stranger gets in 2s
  • Reward clean cliffs that pull the next watch
  • Boost spine-theme + principal fit
  • Spread episodes so the pack isn’t one arc beat

✗ Ranking never

  • Scores by promo_type / label
  • Auto-picks only “cliffhanger” clips
  • Dumps 5 promos from the same episode
  • Ignores spoiler risk on late reveals

Marketer QA · quality gate before you post

Protect heroes. Cut the weak tail.

After ranking builds a campaign pack, a Marketer Agent reviews it the way a growth lead would: keep anything already strong, remove clips with thin hooks, muddy segments, or low standalone clarity. Labels never decide keep vs cut — craft and clarity do.

How the agent decides

Simple rules you can explain in a review meeting

P

Protect (never auto-cut)

Top ~12 by global score, or score ≥ 7.85, or strong craft signals. These are “hero” posts — the agent will not drop them even if a niche rule fires.

C

Cut (weak tail)

Thin / generic hooks, broken or empty segments, low standalone clarity, muddy cold opens. Soft floor keeps pack size roughly in a usable window (about 12–20).

!

Labels stay on the card

emotional / cliffhanger / romantic tags remain for A/B experiments. They are not used as cut reasons — so you can still try every vibe in market.
